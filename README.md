# Medical Insurance Cost Explorer

This project is an interactive R Shiny application that explores medical insurance charges using the Medical Cost Personal Dataset from Kaggle.

## Features

- **Home:** Introduction and instructions for using the app.
- **Distribution:** Interactive histograms for age, BMI, and medical charges, with adjustable bin counts.
- **Scatterplot:** Explore relationships between variables, color points by selected characteristics, and filter observations using sliders.
- **3D Mesh:** Visualize age, BMI, and medical charges in three dimensions using Plotly.

## Dataset

Medical Cost Personal Dataset (1,338 observations)

Source: https://www.kaggle.com/datasets/mirichoi0218/insurance

## R Packages

- shiny
- bslib
- plotly

## Running the App

1. Download the repository.
2. Open `app.R` in RStudio.
3. Install the required R packages.
4. Make sure `insurance.csv` is in the same folder as `app.R`.
5. Click **Run App**.
